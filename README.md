# Evia is now edited in Nisia

Evia lives in **[DDRNFinch/Nisia-Portal](https://github.com/DDRNFinch/Nisia-Portal)**, in `apps/evia`, alongside Milos, Paros, Symi and the Nisia portal, with its full history. **Make changes there, not here.**

This repository still publishes Evia's own address (the one learners installed). `.github/workflows/publish-from-nisia.yml` will publish that address from Nisia's `apps/evia` once it's switched on; until then the old `evia7-pages.yml` publishes this repository's `main` as before. How to switch over: `docs/evia-address/README.md` in Nisia-Portal.
